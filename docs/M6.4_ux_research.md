# Castle Siege · 下一轮用户体验调研

本轮关注六职业版本已有玩法中的五个摩擦点。排序依据是出现频率、对玩家决策的帮助和实施成本。这是研究与交接材料。实测结果来自当前本地版本，未做真人对照试玩。

## 1. 己方上一炮：角度、火力和落点

**当前体验**：战报记录发生了什么，落点特效会消失。等到自己下一轮，玩家往往还要回忆上次用了多少火力，尤其容易把双方的炮混在一起。

**方案**：每侧保存本局最近一次已结算的炮击。轮到己方瞄准时，底栏显示 `Last shot · 45° / 83 · Cover hit`，战场用一个淡色空心标记对应落点。多弹只标一个代表点，优先展示中心弹的落点，无法确定中心弹时只显示合计文案。真正侧边出界时只显示结果。新一炮覆盖记录，重赛清空；显示只读，不自动复用角度或替玩家开火。与现有金色火力箭头配合，形成“看上一炮 → 调一下 → 再打”的学习过程。参考《Worms Armageddon》的上一炮回放功能，此处采用更轻量的静态线索。 [Team17 官方手册](https://ftp.zx.net.nz/pub/archive/ftp.team17.com/pub/t17/manuals/Worms_Armageddon.pdf)

**验收**：左右分别以不同角度开炮，然后轮流瞄准，确认每侧只看到自己的记录。玩家不用翻战报就能说出下一炮要调整什么。工程量小至中。

## 2. 高抛炮弹离开画面时给一个追踪标记

**当前体验**：当前物理允许炮弹越过窗口上沿继续飞。用实装的炮弹更新与碰撞查询试算，75° / 100 有 39 帧在屏幕上方，80° / 100 有 57 帧，分别约 0.65 秒和 0.95 秒。两次最终都落地。

**方案**：至少一枚炮弹越过上沿时，在 HUD 下方的固定区域显示向上的小三角及 `Shell above view`，横坐标跟随炮弹。多弹用一个标记和数量，如 `3 shells above`。炮弹回到画面或结束飞行时立即撤掉标记。不移动镜头，沿用 1280×720 布局。以图形和文字共同表达，保持静音也能看懂。 [Xbox 提示设计指南](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/103)

**验收**：试 75° / 100 和双人右侧镜像；测试空爆分裂后部分子弹留在画面上方的情况。标记不会盖住回合条，不会把真正飞出左右边界的炮弹画成仍在飞。工程量小。

## 3. 让 AI 思考阶段保持响应

**当前体验**：代码先等待 40 帧，再在界面更新里同步运行 AI。用固定 3v3 阵容和默认掩体，右队首回合每档难度测 4 个种子，Easy / Normal / Hard 的决策耗时中位数约为 522 / 602 / 642 ms，样本最慢 688 ms。这测的是 AI 决策本身，尚未测真实窗口的输入延迟。

**方案**：先验收窗口能否在思考期间处理关闭与静音，分别记录展示用等待和实际计算耗时。先检查能否省掉同一决策中对相同瞄准方案的重复模拟。如果仍有明显掉帧，再将当前候选评估拆成少量逐帧工作，保留现有打分、随机顺序和种子结果。利用现有 `Thinking…` 提示，不做虚假进度条。 [Xbox UI 上下文指南](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/114)

**验收**：用带 Gunner、Bombardier、Medic 的 3v3 复测，比较最长单帧、实际下棋耗时和窗口响应。验证 3 档难度的合法行动、重赛清理待处理的旧决策。工程量中，先测再改。

## 4. 保护进行中的对局，结算仍能一键重赛

**当前体验**：实测角色跑向炮台时按一次 R，跑动取消、当前局立刻重置并交换先手。正常结算后一键重赛很方便，但进行中的误按会丢掉整局进度。

**方案**：只在对局进行中，R 打开质量一致的小确认条，写明 `Restart match? Current progress will be lost.`，提供 `Continue` 和 `Restart`，默认继续。打开期间暂停摆动、弹道和 AI 的比赛更新。再次确认应是一次独立输入，按住 R 不应连续确认。结算页的 Rematch 和 R 仍直接开下一局。 [Xbox 高影响操作指南](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/115)

**验收**：分别在跑动、飞行、Reflex 摆动中打开并取消，确认恢复到原帧；确认重开才清空 HP、弹道和回合。工程量小至中。

## 5. 一步进入的试炮场

**当前体验**：六种职业有了，玩家仍要先选队、布防再打到自己的回合，才能比较齐射和空爆的落点。Reflex 的新手也得在正式对局里试节拍。

**方案**：选队页增加次要入口 `Practice`，复用同一个战场和炮击过程。首版只做一套固定掩体和目标，允许切换 Classic / Reflex，并试 Archer、Gunner、Bombardier。每发结算后恢复目标与技能可用性，保留上一次开火参数供比较。Back 回到原选队设置。控制范围为独立的练习场，不加入关卡或教学脚本。Team17 将训练任务独立于正式战役，适合作为这项设计的参考。 [Team17《Worms W.M.D Mobilize》](https://www.team17.com/news/worms-w-md-mobilize-out-now-on-apple-android)

**验收**：新玩家从选队页能直接进场，连续两发试出齐射和空爆的差别，能返回原有设置。练习过程不改变正式对局规则。工程量中，放在上述改动后做。

## 实施顺序

优先做 **1、2、4**，分别改善瞄准复盘、高抛可见性和误操作。第 3 项先做测量与低成本优化。第 5 项单列，等前面稳定再做。沿用现有模块，保留金色火力箭头、六职业和双人分区键位。每项先用固定条件复现，再做脚本验证和一次真人试玩。

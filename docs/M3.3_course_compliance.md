# Castle Siege — course compliance checklist (M3.3, updated for M4.1)

This checklist compares the game with the CS5001 requirements recorded in this project:
`docs/M0_design.md` §8 (rubric), §9 (requirement map), §4.8 (the instructor's example
formulas) and §10.1 (differences C1–C8). The full rubric text is not in the repository, so this
is our reading of it. **No custom rule listed here has been approved by the instructor**; the
ones that need a decision are marked.

M3.4-A (combat foundation) changed the victory rule to the instructor's core requirement:
**the only normal victory is defeating every enemy character.** The fixed castles are replaced
by cover blocks that each team places, and castle destruction no longer wins. M3.4-B added the
cover placement screen (each team places its own cover before the battle; the computer places
its own) and a computer opponent that breaks cover on purpose when it protects a character.
M3.4-C added the run to the cannon: an attacking character (a person's or the computer's) runs to
its team's shared cannon, fires it and runs back. It is drawing only; no rule changed. M4.1
polished the interface (turn banner, damage numbers, clearer cover and result screens); it is
cosmetic only.

Status:
- **Verified**: built, and checked by automated tests (`python -m unittest discover tests`) or
  scripted runs of the real game.
- **Awaiting manual check**: built, and the automated tests pass, but a person still has to
  play-test it. Human gameplay acceptance is pending for the whole game.
- **Missing**: not done yet. Planned for M5 (submission).

## Custom rules (differ from the course's examples or add to them)

These are our design rules. None has been approved by the instructor; each can be changed in
one place if the instructor asks.

| Rule | Ours | Course example / requirement | Where to change it |
|---|---|---|---|
| Round limit and timeout (C7) | A match that reaches the end of round 30 (complete rounds) without an elimination is a draw. HP and cover never pick a winner | No round limit mentioned; win or lose | `battle.ROUND_LIMIT` |
| Draws | Possible only through the timeout (in play, no shot can defeat both teams at once) | Win or lose | (follows from C7) |
| Deployable cover (C8) | Each team places up to 6 blocks (100 HP) on 8 fixed slots before the battle (the placement screen starts from the default cover). Blocks stop shots, and a standing block between an explosion and a character absorbs the whole blast for that character. Blocks never decide the winner | Not specified | `castle.MAX_BLOCKS`, `castle.COLUMN_X`, `castle.DEFAULT_LAYOUT`; an empty layout plays as an open field |
| The computer's cover (M3.4-B) | A two-block tower next to its characters, then 4 blocks on random allowed slots: always the full budget, the same rules as a player | Not specified | `ai.TOWER`, `AIController.choose_layout` |
| Hidden cover in two-player setup (M3.4-B) | While one team places its cover, the other team's cover is not shown; both are visible in battle | Not specified | `Game.draw_cover_screen` |
| Damage formula (§4.8) | ATK − DEF, minimum 1; deterministic, so the tests can check exact numbers | ATK − DEF + a random −5 to +10 | `calculate_damage` |
| Defend (C5) and Cover Guard (M3.2) | Defend halves the defender's damage after DEF. While a team defends, enemy shots also do half damage to its blocks | Defend reduces damage by 50 % | `CASTLE_GUARD_PERCENT = 0` turns Cover Guard off |
| Attacks can miss (C3) | Characters attack through the team's cannon, aimed with angle and power | May assume every attack hits | — |
| How characters attack (C6) | The acting character "operates" the team's single cannon, which stands in front of the cover; its stats set the damage. Since M3.4-C it is seen running to the cannon and back (the shot still starts at the cannon) | Characters attack | `animation.py` (timing), `Game.fire_pending_shot` |
| AI defence (C4) | Probabilistic: the higher Defend chance applies when any living AI character is below half HP. The weakest one then defends, or the Knight Rallies | "AI defends below 50 % HP" | `DIFFICULTY_SETTINGS` (set the chance to 100 %) |
| Engineer Repair (M3.2) | Up to 150 HP for damaged standing blocks; cooldown 4; destroyed blocks are not rebuilt; unavailable when nothing can be repaired | Not specified | `Engineer.REPAIR_POOL` |
| Who moves first (M3.3) | LEFT in the first match; the first mover alternates on every rematch | Not specified | `Game.rematch` |

Removed in M3.4-A: the 60 % castle victory (C2 is now compliant), the round-limit
tie-breakers, and the M1 cannon duel.
